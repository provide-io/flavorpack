    Flavor Pack Documentation¶

    Welcome to the official documentation for Flavor Pack (flavorpack), the Progressive Secure Package Format (PSPF) packaging system.

    Documentation Structure¶

    For Users¶

    • User Guide - Getting started, creating packages, and using Flavor Pack
    • Changelog - Version history and release notes

    For Developers¶

    • Development Guide - Setting up development environment, building, and testing
    • Architecture - Technical architecture and design decisions
    • CI/CD Pipeline - Continuous integration and deployment

    Reference¶

    • API Reference - Command reference and usage examples
    • Formal Specifications (RFCs)
    • PSPF/2025 Specification - The base specification for the Progressive Secure Package Format.
    • Staged Payload Architecture (SPA) Extension - An optional extension for improving startup performance.
    • Versioning - Version strategy and compatibility
    • Troubleshooting - Common issues and solutions
