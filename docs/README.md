# Flavor Documentation

Welcome to the Flavor documentation! This directory contains the canonical documentation for the Flavor packaging system and the Progressive Secure Package Format (PSPF/2025).

## 📚 Core Documentation

### For Users & Developers

- **[SPECIFICATION.md](SPECIFICATION.md)** - The complete and canonical PSPF/2025 format specification. All implementations must adhere to this document.
- **[RATIONALE.md](RATIONALE.md)** - The "why" behind PSPF, explaining the design goals and the problems it aims to solve.
- **[ARCHITECTURE.md](ARCHITECTURE.md)** - System design and architectural decisions.
- **[DEVELOPMENT.md](../DEVELOPMENT.md)** - The primary guide for contributors, detailing the current state of the code, the development roadmap, and instructions for building and testing.
- **[INTEGRATION.md](INTEGRATION.md)** - Guide for integrating Flavor with other tools and systems.

## 📁 Examples

The `examples/` directory contains working examples:

- **[hello-pspf](../examples/hello-pspf/)** - A simple, multi-language "Hello World" example for PSPF 2025.
- **[simple-provider](examples/simple-provider/)** - A basic Terraform provider example.
