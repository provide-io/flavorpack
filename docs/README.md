# Flavor Documentation

This directory contains the canonical documentation for the Flavor packaging system and the Progressive Secure Package Format (PSPF/2025).

## 📚 Core Documentation

- **[SPECIFICATION.md](SPECIFICATION.md)** - The complete and canonical PSPF/2025 format specification. All implementations must adhere to this document.
- **[RATIONALE.md](RATIONALE.md)** - The "why" behind PSPF, explaining the design goals and the problems it aims to solve.
- **[DEVELOPMENT.md](../DEVELOPMENT.md)** - The primary guide for contributors, detailing the current architecture, state of the code, and instructions for building and testing.
