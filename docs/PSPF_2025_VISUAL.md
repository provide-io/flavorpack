# PSPF 2025 Format Visualization

## Proposed Structure: Metadata-First Design

```
                           PSPF 2025 FILE LAYOUT
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│  METADATA.TGZ (Variable Size)                                       │ Offset: 0
│  ┌───────────────────────────────────┐                            │
│  │ psp.json                          │                            │
│  │ integrity/seal.sig                │                            │
│  │ integrity/seal.pem                │                            │
│  │ keys/*, signatures/*, etc.        │                            │
│  └───────────────────────────────────┘                            │
│                                                                     │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  SLOT 0 (Variable Size)                                            │ 
│  ┌───────────────────────────────────┐                            │
│  │ e.g., python-3.13.tgz             │                            │
│  └───────────────────────────────────┘                            │
│                                                                     │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  SLOT 1 (Variable Size)                                            │
│  ┌───────────────────────────────────┐                            │
│  │ e.g., myapp.whl                   │                            │
│  └───────────────────────────────────┘                            │
│                                                                     │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  ... SLOT N                                                         │
│                                                                     │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  LAUNCHER BINARY (Variable Size)                                   │
│  ┌───────────────────────────────────┐                            │
│  │ Platform-specific executable      │                            │
│  │ (darwin_arm64, linux_amd64, etc.) │                            │
│  └───────────────────────────────────┘                            │
│                                                                     │
├─────────────────────────────────────────────────────────────────────┤
│  FOOTER (64 bytes)                                                 │ EOF - 80
│  ┌─────────────────────────────────────────────┐                  │
│  │ metadata_size:     8 bytes                  │                  │
│  │ launcher_offset:   8 bytes                  │                  │
│  │ launcher_size:     8 bytes                  │                  │
│  │ metadata_checksum: 4 bytes (Adler-32)       │                  │
│  │ footer_checksum:   4 bytes (Adler-32)       │                  │
│  │ reserved:         32 bytes                  │                  │
│  └─────────────────────────────────────────────┘                  │
├─────────────────────────────────────────────────────────────────────┤
│  EMOJI MAGIC (16 bytes)                                            │ EOF - 16
│  ┌─────────────────────────────────────────────┐                  │
│  │ 📦 🐹 🦄 🪄                                   │                  │
│  │ [P][L][R][M]                                │                  │
│  └─────────────────────────────────────────────┘                  │
└─────────────────────────────────────────────────────────────────────┘
                                                                      EOF
```

## Reading Flow Visualization

```
Step 1: Read backwards from EOF
        ←────────────────────────┐
                                 ↓
[..................📦🐹🦄🪄] Check magic
                   ↑
                   └─ Always 📦...🪄

Step 2: Read footer (EOF - 80)
        ←───────────────┐
                        ↓
[..........Footer(64)📦🐹🦄🪄] Get metadata_size

Step 3: Read from start
↓
[Metadata.tgz................] Parse psp.json
 └─ Size from footer

Step 4: Use metadata to find everything else
```

## Alternative: Ultra-Minimal (No Footer)

```
┌─────────────────────────────────────────────────────────────────────┐
│  METADATA.TGZ                                                       │
├─────────────────────────────────────────────────────────────────────┤
│  SLOT 0                                                             │
├─────────────────────────────────────────────────────────────────────┤
│  SLOT 1                                                             │
├─────────────────────────────────────────────────────────────────────┤
│  ... SLOT N                                                         │
├─────────────────────────────────────────────────────────────────────┤
│  LAUNCHER BINARY                                                    │
├─────────────────────────────────────────────────────────────────────┤
│  METADATA_SIZE (8 bytes) │ Just the size as uint64                 │ EOF - 24
├─────────────────────────────────────────────────────────────────────┤
│  📦🐹🦄🪄 (16 bytes)     │ Emoji magic                              │ EOF - 16
└─────────────────────────────────────────────────────────────────────┘
```

## Size Comparison

Current v0.1:
```
[Launcher][UV][Python][Metadata][Payload][Sig][Key][Footer(120)][Magic]
```

Proposed 2025:
```
[Metadata][Slots...][Launcher][Footer(64)][📦🐹🦄🪄]
```

Ultra-minimal:
```
[Metadata][Slots...][Launcher][Size(8)][📦🐹🦄🪄]
```
