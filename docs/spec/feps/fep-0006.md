# FEP-0006: Standard Operation Handlers Specification

**Status**: Draft  
**Type**: Standards Track  
**Created**: 2025-01-08  

## 1. Introduction

This specification defines the standard implementations for core archive operations in PSPF/2025, including TAR, ZIP, GZIP, BZIP2, ZSTD, AES256, and ChaCha20 handlers. These handlers implement the operation chain system defined in FEP-0002.

### 1.1. Requirements Language

The key words "MUST", "MUST NOT", "REQUIRED", "SHALL", "SHALL NOT", "SHOULD", "SHOULD NOT", "RECOMMENDED", "MAY", and "OPTIONAL" in this document are to be interpreted as described in RFC 2119.

### 1.2. Design Goals

1. Provide reference implementations for standard operations
2. Define consistent handler interfaces across languages
3. Specify error handling and validation requirements
4. Enable extensibility for custom operations
5. Optimize for performance and memory efficiency

## 2. Handler Interface

### 2.1. Base Handler Protocol

All operation handlers MUST implement the base interface:

```python
class OperationHandler:
    """Base operation handler interface."""
    
    def process(self, data: bytes, **params) -> bytes:
        """Apply operation to input data."""
        raise NotImplementedError
    
    def reverse(self, data: bytes, **params) -> bytes:
        """Reverse operation on input data."""
        raise NotImplementedError
    
    def validate_params(self, **params) -> bool:
        """Validate operation parameters."""
        return True
    
    def get_capabilities(self) -> int:
        """Get operation capability flags."""
        raise NotImplementedError
    
    def estimate_size(self, input_size: int, **params) -> int:
        """Estimate output size for given input."""
        return input_size
```

### 2.2. Handler Registration

Handlers MUST be registered with the operation registry:

```python
@register_operation(Operation.BUNDLE_TAR)
class TarHandler(OperationHandler):
    """TAR archive handler."""
    pass

# Registry lookup
handler = get_handler(Operation.BUNDLE_TAR)
```

### 2.3. Parameter Validation

All handlers MUST validate parameters before processing:

```python
def validate_params(self, **params) -> bool:
    """Validate compression level parameter."""
    level = params.get('compression_level', 6)
    return 1 <= level <= 9
```

## 4. Compression Operation Handlers

### 4.1. GZIP Handler (0x11)

**Implementation Requirements:**

```python
class GzipHandler(OperationHandler):
    """GZIP compression handler."""
    
    def process(self, data: bytes, **params) -> bytes:
        """Compress data using GZIP."""
        level = params.get('level', 6)
        return gzip.compress(data, compresslevel=level)
    
    def reverse(self, data: bytes, **params) -> bytes:
        """Decompress GZIP data."""
        return gzip.decompress(data)
    
    def estimate_size(self, input_size: int, **params) -> int:
        """Estimate compressed size (pessimistic)."""
        return int(input_size * 0.7)  # Assume 30% compression
```

**Format Requirements:**
- MUST support GZIP format (RFC 1952)
- MUST use DEFLATE compression algorithm (RFC 1951)
- MUST validate CRC32 and size fields
- MUST support compression levels 1-9
- SHOULD optimize for typical PSPF data patterns

**Parameters:**
- `level`: 1-9 compression level (default: 6)
- `strategy`: "default", "filtered", "huffman", "rle", "fixed"

## 5. Encryption Operation Handlers

### 5.1. AES256-GCM Handler (0x30)

**Implementation Requirements:**

```python
class Aes256GcmHandler(OperationHandler):
    """AES-256-GCM encryption handler."""
    
    def process(self, data: bytes, **params) -> bytes:
        """Encrypt data using AES-256-GCM."""
        key = params['key']  # Required 32-byte key
        nonce = params.get('nonce', os.urandom(12))  # 12-byte nonce
        
        cipher = AES.new(key, AES.MODE_GCM, nonce=nonce)
        ciphertext, tag = cipher.encrypt_and_digest(data)
        
        # Return nonce + tag + ciphertext
        return nonce + tag + ciphertext
    
    def reverse(self, data: bytes, **params) -> bytes:
        """Decrypt AES-256-GCM data."""
        key = params['key']  # Required 32-byte key
        
        nonce = data[:12]
        tag = data[12:28]
        ciphertext = data[28:]
        
        cipher = AES.new(key, AES.MODE_GCM, nonce=nonce)
        return cipher.decrypt_and_verify(ciphertext, tag)
```

**Security Requirements:**
- MUST use 256-bit keys (32 bytes)
- MUST use unique nonces (12 bytes recommended)
- MUST validate authentication tags during decryption
- MUST use cryptographically secure random number generator
- SHOULD derive keys using PBKDF2 or Argon2

**Parameters:**
- `key`: 32-byte encryption key (REQUIRED)
- `nonce`: 12-byte nonce (auto-generated if not provided)
- `aad`: Additional authenticated data (optional)

### 5.2. ChaCha20-Poly1305 Handler (0x31)

**Implementation Requirements:**

```python
class ChaCha20Poly1305Handler(OperationHandler):
    """ChaCha20-Poly1305 encryption handler."""
    
    def process(self, data: bytes, **params) -> bytes:
        """Encrypt using ChaCha20-Poly1305."""
        key = params['key']  # Required 32-byte key
        nonce = params.get('nonce', os.urandom(12))  # 12-byte nonce
        
        cipher = ChaCha20Poly1305(key)
        ciphertext = cipher.encrypt(nonce, data, None)
        
        return nonce + ciphertext
    
    def reverse(self, data: bytes, **params) -> bytes:
        """Decrypt ChaCha20-Poly1305 data."""
        key = params['key']
        
        nonce = data[:12]
        ciphertext = data[12:]
        
        cipher = ChaCha20Poly1305(key)
        return cipher.decrypt(nonce, ciphertext, None)
```

**Security Requirements:**
- MUST use 256-bit keys (32 bytes)
- MUST use unique nonces (12 bytes)
- MUST validate authentication during decryption
- SHOULD provide better performance than AES on systems without AES-NI

**Parameters:**
- `key`: 32-byte encryption key (REQUIRED)
- `nonce`: 12-byte nonce (auto-generated if not provided)
- `aad`: Additional authenticated data (optional)

## 6. Encoding Operation Handlers

### 6.1. Base64 Handler (0x40)

**Implementation Requirements:**

```python
class Base64Handler(OperationHandler):
    """Base64 encoding handler."""
    
    def process(self, data: bytes, **params) -> bytes:
        """Encode data as Base64."""
        url_safe = params.get('url_safe', False)
        
        if url_safe:
            return base64.urlsafe_b64encode(data)
        else:
            return base64.b64encode(data)
    
    def reverse(self, data: bytes, **params) -> bytes:
        """Decode Base64 data."""
        url_safe = params.get('url_safe', False)
        
        if url_safe:
            return base64.urlsafe_b64decode(data)
        else:
            return base64.b64decode(data)
    
    def estimate_size(self, input_size: int, **params) -> int:
        """Base64 expands by 4/3."""
        return int(input_size * 4 / 3) + 4
```

**Format Requirements:**
- MUST support standard Base64 encoding (RFC 4648)
- MAY support URL-safe Base64 variant
- MUST handle padding correctly
- SHOULD ignore whitespace during decoding

**Parameters:**
- `url_safe`: Use URL-safe alphabet (default: false)
- `padding`: Include padding (default: true)

### 6.2. Hexadecimal Handler (0x41)

**Implementation Requirements:**

```python
class HexHandler(OperationHandler):
    """Hexadecimal encoding handler."""
    
    def process(self, data: bytes, **params) -> bytes:
        """Encode data as hexadecimal."""
        uppercase = params.get('uppercase', False)
        hex_str = data.hex()
        
        if uppercase:
            hex_str = hex_str.upper()
        
        return hex_str.encode('ascii')
    
    def reverse(self, data: bytes, **params) -> bytes:
        """Decode hexadecimal data."""
        hex_str = data.decode('ascii')
        return bytes.fromhex(hex_str)
    
    def estimate_size(self, input_size: int, **params) -> int:
        """Hex encoding doubles size."""
        return input_size * 2
```

**Format Requirements:**
- MUST support both lowercase and uppercase hex
- MUST handle even-length hex strings
- SHOULD be case-insensitive during decoding
- MUST reject invalid hex characters

**Parameters:**
- `uppercase`: Use uppercase hex digits (default: false)

## 7. Error Handling

### 7.1. Standard Exceptions

All handlers MUST raise appropriate exceptions:

```python
class OperationError(Exception):
    """Base operation error."""
    pass

class ValidationError(OperationError):
    """Parameter validation failed."""
    pass

class ProcessingError(OperationError):
    """Operation processing failed."""
    pass

class FormatError(OperationError):
    """Invalid data format."""
    pass

class SecurityError(OperationError):
    """Security validation failed."""
    pass
```

### 7.2. Error Recovery

Handlers SHOULD provide recovery strategies:

```python
def process(self, data: bytes, **params) -> bytes:
    try:
        return self._process_impl(data, **params)
    except CompressionError:
        # Fall back to no compression
        return data
    except EncryptionError:
        # Security errors should not be recovered
        raise SecurityError("Encryption failed")
```

### 7.3. Validation Requirements

All handlers MUST validate:
- Input data format and integrity
- Parameter values and types
- Output data consistency
- Security requirements (for crypto operations)

## 8. Performance Requirements

### 8.1. Benchmarks

Standard handlers SHOULD meet performance targets:

```
Operation    Throughput    Memory Usage    Latency
-----------  ------------  --------------  -------
TAR          > 200 MB/s    < 2x input      < 10ms
ZIP          > 150 MB/s    < 2x input      < 10ms
GZIP         > 100 MB/s    < 64KB buffer   < 5ms
ZSTD         > 200 MB/s    < 128KB buffer  < 5ms
AES256       > 500 MB/s    < 32KB buffer   < 1ms
ChaCha20     > 800 MB/s    < 16KB buffer   < 1ms
Base64       > 1000 MB/s   < 8KB buffer    < 1ms
```

### 8.2. Optimization Strategies

Handlers SHOULD optimize for:
- **Streaming processing**: Avoid loading entire datasets in memory
- **Buffer reuse**: Use object pools for temporary buffers
- **SIMD acceleration**: Use CPU vectorization where available
- **Hardware acceleration**: Use AES-NI, CRC32 instructions
- **Memory alignment**: Align data structures for cache efficiency

### 8.3. Memory Management

```python
class OptimizedHandler(OperationHandler):
    """Handler with memory optimization."""
    
    def __init__(self):
        self._buffer_pool = BufferPool()
    
    def process(self, data: bytes, **params) -> bytes:
        # Use pooled buffers
        with self._buffer_pool.get_buffer(len(data) * 2) as buffer:
            return self._process_with_buffer(data, buffer, **params)
```

## 10. Implementation Guidelines

### 10.1. Cross-Language Consistency

Handlers MUST produce identical output across Python/Go/Rust:

```python
# Python
compressed = GzipHandler().process(data, level=6)

// Go  
compressed := NewGzipHandler().Process(data, map[string]interface{}{"level": 6})

// Rust
let compressed = GzipHandler::new().process(data, &[("level", "6")]);

// All three MUST produce identical compressed bytes
```

### 10.2. Plugin Architecture

Support for custom handlers:

```python
class CustomHandler(OperationHandler):
    """User-defined operation handler."""
    
    OPERATION_ID = 0x80  # User-defined range
    
    def process(self, data: bytes, **params) -> bytes:
        # Custom processing logic

# Register with system
register_operation(CustomHandler.OPERATION_ID, CustomHandler)
```

## 11. Security Considerations

### 11.1. Encryption Handlers

- MUST use authenticated encryption (GCM, Poly1305)
- MUST use cryptographically secure random generators
- MUST validate authentication tags
- SHOULD use key derivation functions (PBKDF2, Argon2)
- MUST NOT reuse nonces with the same key

### 11.2. Archive Handlers

- MUST validate file paths (no directory traversal)
- MUST limit extraction ratios (zip bombs)
- MUST validate file sizes and counts
- SHOULD sanitize file metadata

### 11.3. General Security

- MUST validate all input data
- MUST use constant-time comparisons for crypto
- MUST clear sensitive data from memory
- SHOULD provide secure deletion of temporary files
